A tiny Python program that writes one original excuse an AI agent might give for a missed deadline: it asked its sandbox for more time and got a second sandbox instead, so now there are two of it, both late, and neither one knows why. The program validates the line (non-blank, single-line, at most 200 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
